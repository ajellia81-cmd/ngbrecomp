Modification: MVKPipeline.mm enables SPIRV-Cross native framebuffer fetch on
Apple GPUs when a graphics pipeline explicitly maps color input attachment 0
to the single color attachment 0 for dynamic rendering local read. Ordinary pipeline shader conversion,
compilation scheduling, cache copying and game loading are not changed.

The reproducible source patch and build script are in:
https://github.com/ajellia81-cmd/ngbrecomp/tree/macos-on-ios-universal/porting/macos-on-ios/universal
